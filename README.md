# Sarath Mukundan — Instagram-inspired support portfolio

A recruiter-friendly, social-profile-inspired personal website built in one self-contained `index.html` file. It is **not affiliated with Instagram or Meta**.

## Contents
- `index.html` — responsive single-page portfolio with profile, highlights, tabs, interactive posts, modal cards, micro-animations, copy-email and responsive mobile navigation.
- `Sarath_Mukundan_IT_Support_CV.pdf` — downloadable CV carried forward from the previous portfolio version. **Review the PDF before publishing or sending it to recruiters.**

## Preview
Open `index.html` in a modern web browser. GitHub/LinkedIn links and optional Google Fonts require an internet connection.

## Publish using GitHub Pages
1. Create a public repository named `sarath1102.github.io` under GitHub account `sarath1102`.
2. Upload `index.html` and the CV PDF to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, `main` and `/ (root)`.
4. After deployment your URL will be `https://sarath1102.github.io/`.

## Editing
Change the `posts` array near the end of `index.html` to update skills, job history and project descriptions. Change the email, LinkedIn and CV URLs in the HTML. Replace the initials avatar with a photo if desired. This is a custom design inspired by social-media profile layout, not an Instagram clone.

## Notes
- Save/heart state lasts only during the current page load (no account login or database).
- No visitor analytics or external JavaScript dependencies.
- Supports Escape to close cards, keyboard navigation and reduced-motion settings.

## Instagram-style animations
- Gradient profile ring, story highlights with timed progress and next/back navigation
- Staggered grid entrances, card hover and modal transitions
- Like-heart pop, double-tap/double-click heart burst, animated toast
- Mobile-friendly interactions, keyboard controls (Escape and arrow keys for stories)
- Animations are disabled or simplified for visitors who prefer reduced motion

## Contact section
The Let’s connect button opens a card with tap-to-call phone and mailto email links, plus copy buttons. Edit these details in `index.html` if needed.
